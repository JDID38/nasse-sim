# Cadre de participation

Les critiques du modèle, de ses hypothèses et de ses résultats sont encouragées. Les attaques personnelles, le harcèlement, les propos discriminatoires, les menaces et la divulgation de données personnelles ne sont pas acceptés.

Discuter les arguments avec des exemples et des sources ; distinguer désaccord technique et mise en cause des personnes. Accueillir les débutants et les contributions non techniques.

Les responsables du dépôt peuvent modérer les échanges, masquer ou supprimer les contenus contraires à ce cadre et restreindre les accès en cas d'abus. Utiliser les fonctions de signalement de GitHub ; ne pas republier des informations personnelles dans une nouvelle issue.
